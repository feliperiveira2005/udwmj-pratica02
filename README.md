# UDWMJ - Prática 02

Atividade da disciplina de Desenvolvimento Web.

## Exercícios

### Exercício 01
Arquivo `pratica02exercicio01.html`.

Demonstra o uso de `alert()` dentro do `<body>`.

### Exercício 02
Arquivo `pratica02exercicio02.html`.

Demonstra o uso de `alert()` dentro do `<head>`.

### Exercício 03
Arquivos:
- `pratica02exercicio03.html`
- `pratica02exercicio03.js`

Demonstra o uso de JavaScript em arquivo externo.

### Exercício 04
Arquivos:
- `pratica02exercicio04.html`
- `pratica02exercicio04.css`
- `pratica02exercicio04.js`

A página solicita o nome do usuário por meio de `prompt()` e exibe uma saudação personalizada, formatada por um arquivo CSS externo.

Exemplo: `Olá, Ana!`

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
